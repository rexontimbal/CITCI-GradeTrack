Before you upload

You can upload CITCI's own class-record layout as-is. If you're instead exporting a plain Excel or CSV file from another system, preparing it this way keeps the import quick and accurate:

  • Row 1 must be column headers only. No title row, no merged cells, and no blank row above it.
  • One row per student, per class. Don't mix more than one class's students in the same file unless each row also has its own Subject column.
  • Recognized column types (any column name is fine; you'll confirm each one on the next screen):
    • Student ID or Student Name (at least one, needed to tell students apart)
    • Attendance, Quiz, Recitation, Project, and Exam scores or averages
    • Periodic grades if you have them, e.g. Prelim Grade, Midterm Grade
    • Final Grade (required, used to determine at-risk students)
    • Remarks or Status, e.g. Passed / Failed / INC / Dropped (optional, but recommended)
  • Columns you don't recognize or don't need can be left unmapped. They're simply ignored.

Student identities are masked (SHA-256) the moment a row is read. No names or ID numbers are ever saved.
